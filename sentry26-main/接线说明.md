# 哨兵接线说明

适用于 `sentry26-main`。哨兵底盘为**四全向轮**，每个轮子由一台 M3508 驱动，共 **4 台 M3508**。三全向轮底盘属于排球车 `sentry26-robovolley26`。

## 底盘 C 板

- **CAN1**：四个底盘 M3508 电调，反馈 ID 为 `0x201` 至 `0x204`，控制帧 ID 为 `0x200`。CAN1 还接大云台 yaw 电机 MF9025 和超级电容。
- **CAN2**：连接云台 C 板，默认也接收 NUC 的 `0x401` 至 `0x403` 控制帧。遥控数据由云台板以 `0x602` 转发。
- **USART1**：裁判系统串口，115200。
- **USART6**：向 NUC 回传裁判原始帧，115200。将 `NUC_USE_CAN` 改为 `0` 并重新编译后，同一串口也用于接收 NUC 的 UART 控制帧。

## 云台 C 板

- **CAN1**：两个小云台 GM6020、两个摩擦轮 M3508、一个拨弹盘 M2006。
- **CAN2**：连接底盘 C 板和 NX。
- **USART1**：HI12，115200，当前模块输出 100 Hz，后续用于小云台瞄准结构。
- **USART3 / DBUS 专用口**：遥控接收机。
- **USART6**：大云台 IM900，115200。IM900 TX 接 C 板 RX（PG9），若需向模块发送配置，IM900 RX 接 C 板 TX（PG14），信号地共地。

## VOFA 无线调试

配置集中在 `APP/robot_config.h`，只选择串口，修改后重新编译并烧录。两块板默认均关闭 VOFA。无线调试器和 VOFA+ 设置 115200，电脑端选择 JustFloat。

- 云台常规电机调试或观察 HI12：`GIMBAL_VOFA_PORT` 改为 `VOFA_PORT_UART6`。无线调试器接 USART6，暂停 IM900 和大 yaw 转发，HI12 继续工作。
- 观察 IM900：`GIMBAL_VOFA_PORT` 改为 `VOFA_PORT_UART1`。无线调试器接 USART1，暂停 HI12，IM900 继续工作并向底盘转发大 yaw。
- 底盘本地调试：`CHASSIS_VOFA_PORT` 改为 `VOFA_PORT_UART6`，保持 `NUC_USE_CAN=1`。无线调试器接底盘 USART6，暂停裁判数据回传，USART1 仍接收裁判数据，NUC 仍通过 CAN2 控制。
- 关闭对应板的 VOFA：将该板的端口配置改回 `VOFA_PORT_OFF`。

USART1 输出时，C 板 PA9 → 无线调试器 RX；USART6 输出时，C 板 PG14 → 无线调试器 RX。调试器与 C 板共地，只查看曲线时调试器 TX 悬空。使用调试接口前拔下该接口的原模块。

### 选择要观察的变量

云台修改 `APP/gimbal.c` 的 `gimbal_debug()`，底盘修改 `APP/chassis.c` 的 `chassis_debug()`。直接编辑函数内的 `const fp32 debug[] = {...};`，变量在数组中的顺序对应 VOFA 通道顺序，可混合角度、电机转速和其他本板状态。首次调试输出时按数组长度初始化 VOFA，因此增加或减少数组项后无需另改通道数量，重新编译烧录即可。每帧最多 31 路 float（受当前 128 字节发送上限限制）。

当前云台数组含 pitch/yaw 目标及实测角、pitch/yaw 电机反馈转速、摩擦轮 0 及拨弹盘反馈转速，共 8 路。底盘数组为四轮目标转速，随后四轮反馈转速，共 8 路。

例如观察 IM900 的 yaw/pitch，在云台 `debug[]` 中填写 `gimbal_ptr->im900->imu_data.yaw` 和 `gimbal_ptr->im900->imu_data.pitch`，并选择 USART1 接 VOFA。观察 HI12 时填写 `gimbal_ptr->hi12->imu_data.yaw` 和 `gimbal_ptr->hi12->imu_data.pitch`，并选择 USART6。需要一次读取多字段的一致快照时，IM900 可使用 `IM900_GetData()`，HI12 可在短临界区复制其数据再填写数组。

未连接或未更新的 IMU 不能提供实时观测值。云台约 200 Hz、底盘约 100 Hz 输出，发送频率与 IMU 采样频率分别计算。


IM900 需预先由厂家上位机设为主动上报欧拉角，C 板收到有效欧拉角帧后才发 CAN2 `0x603`（DLC 8，前 4 字节为小端 float yaw，单位度）。底盘记录首条有效帧的 yaw 为偏置，首次计算相对 yaw 为零。该参考系与导航地图世界系的初始航向偏置仍需联调对齐，安装轴向和正负方向也需实测。

两块板的 CAN1 和 CAN2 均配置为 1 Mbit/s。模块分配以 [模块初始化](APP/module_init.c) 为准。
